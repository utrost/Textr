## Findings fixed during validation

A write-only output provider reproduced a SecurityException when an internal reader handoff forwarded URI grant flags the provider had not granted for reading. Internal same-app opening no longer invents grant delegation. Available read access is retained only after successful reading; a read denial uses normal reader recovery while the completed write remains successful. No exported component or signature permission was weakened.

Replacing the collection screen’s root after navigation could miss insets and clip Done. Root installation now requests insets after attachment; explicit layout sizing and full-visible-button checks pass at normal and 200% text.
