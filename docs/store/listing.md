## English

**Name:** Textr

**Short description:** Read, compare and edit text copies offline. No ads.

**Full description:**

Open everyday text files with Textr, a reader and inspector for Android 10 and newer. Make changes through explicit editing of separate TXT/Markdown copies. No accounts, ads, analytics or app network permission.

Open files through Android’s system picker or from another app’s Open with or Share action. Read plain text, highlighted source and supported Markdown, JSON and calendar previews. CSV files start as text, with an optional table view.

Read saved HTML as Markdown and export a new Markdown file. Navigate JSON/XML structure or compare two source documents in unified or side-by-side views. Edit a separate TXT/Markdown copy with undo/redo, find/replace, private recovery and Save as.

Search the current view or complete source, select and copy text, adjust global/per-document size, wrapping, font and spacing, and choose a light or dark appearance. Revisit recent files, switch between up to five open documents and keep named bookmarks. An optional sidebar makes use of larger foldable and tablet windows. English and German interfaces are included.

Textr supports text files up to 5 MiB. Supported formats include TXT, LOG, configuration files, JSON, Markdown, YAML, TOML, XML, CSV/TSV, .env, .properties, Dockerfile, Java, JavaScript, TypeScript/TSX, CSS, HTML, Kotlin, Python, shell, SQL, diff and iCalendar. Preview and highlighting limits apply; plain text remains available.

Textr preserves original files; exports and edits are saved as separate documents. Copy editing retains one app-private recovery draft until discarded or its matching revision is saved. It does not manage your files. Android’s default-app choices depend on the sending app and reported file type. External document providers may independently use the network. Tapped links open in an external app. Markdown images and embedded HTML are not rendered; calendar recurrence is not expanded.

Free software under GPL-3.0-only. Source and help: https://github.com/utrost/Textr

## Deutsch

**Name:** Textr

**Kurzbeschreibung:** Text offline lesen, vergleichen und Kopien bearbeiten. Ohne Werbung.

**Beschreibung:**

Textdateien lesen, ohne versehentlich etwas zu verändern. Textr ist eine Lese-App für Android 10 und neuer mit ausdrücklicher Bearbeitung separater TXT-/Markdown-Kopien – ohne Konten, Werbung, Analysefunktionen oder eigene Netzwerkberechtigung.

Öffne Dateien über die Android-Systemauswahl oder über Öffnen mit und Teilen in anderen Apps. Wähle zwischen Klartext, hervorgehobenem Quelltext und unterstützten Vorschauen für Markdown, JSON und Kalender. CSV-Dateien starten als Text und bieten eine optionale Tabellenansicht.

Lies gespeichertes HTML als Markdown und exportiere eine neue Markdown-Datei. Navigiere durch JSON-/XML-Strukturen oder vergleiche zwei Dokumente gemeinsam oder nebeneinander. Bearbeite eine separate TXT-/Markdown-Kopie mit Rückgängig/Wiederholen, Suchen/Ersetzen, privater Wiederherstellung und Speichern unter.

Durchsuche die Ansicht oder den vollständigen Quelltext, markiere und kopiere Text, passe Textgröße, Zeilenumbruch, Schrift und Abstände global oder je Dokument an und wähle eine helle oder dunkle Darstellung. Öffne zuletzt gelesene Dateien erneut, wechsle zwischen bis zu fünf Dokumenten und speichere benannte Lesezeichen. Eine optionale Dateiseitenleiste nutzt große Bildschirme auf Foldables und Tablets. Die Oberfläche ist auf Deutsch und Englisch verfügbar.

Textr unterstützt Textdateien bis 5 MiB, darunter TXT, LOG, Konfigurationen, JSON, Markdown, YAML, TOML, XML, CSV/TSV, .env, .properties, Dockerfile, Java, JavaScript, TypeScript/TSX, CSS, HTML, Kotlin, Python, Shell, SQL, Diff und iCalendar. Vorschau und Hervorhebung haben Grenzen; Klartext bleibt verfügbar.

Textr erhält Originaldateien unverändert; Exporte und Änderungen werden als separate Dokumente gespeichert. Die Kopiebearbeitung behält einen privaten Wiederherstellungsentwurf bis zum Verwerfen oder erfolgreichen Speichern derselben Fassung. Textr verwaltet keine Dateien. Android entscheidet anhand der sendenden App und des gemeldeten Dateityps über Standard-Apps. Externe Dokumentanbieter können selbst das Netzwerk nutzen. Angetippte Links öffnen sich in einer anderen App. Markdown-Bilder und eingebettetes HTML werden nicht dargestellt; Kalenderwiederholungen werden nicht aufgelöst.

Freie Software unter GPL-3.0-only. Quellcode und Hilfe: https://github.com/utrost/Textr
