## English

**Name:** Textr

**Short description:** Read text, code and Markdown offline. Simple, read-only, no ads.

**Full description:**

Open everyday text files without an editor getting in the way. Textr is a read-only viewer for Android 10 and newer, with no accounts, ads, analytics or app network permission.

Open files through Android’s system picker or from another app’s Open with or Share action. Read plain text, highlighted source and supported Markdown, JSON and calendar previews. CSV files start as text, with an optional table view.

Search the current view or complete source, select and copy text, adjust text size and wrapping, and choose a light or dark appearance. Revisit recent files, switch between up to five open documents and keep named bookmarks. An optional sidebar makes use of larger foldable and tablet windows. English and German interfaces are included.

Textr supports text files up to 5 MiB. Supported formats include TXT, LOG, configuration files, JSON, Markdown, YAML, TOML, XML, CSV, Java, JavaScript, CSS, HTML source, Kotlin, Python, shell, SQL, diff and iCalendar. Preview and highlighting limits apply; plain text remains available.

Textr does not edit or manage your files. Android’s default-app choices depend on the sending app and reported file type. External document providers may independently use the network. Tapped links open in an external app. Markdown images and embedded HTML are not rendered; calendar recurrence is not expanded.

Free software under GPL-3.0-only. Source and help: https://github.com/utrost/Textr

## Deutsch

**Name:** Textr

**Kurzbeschreibung:** Text, Code und Markdown offline lesen. Schreibgeschützt und ohne Werbung.

**Beschreibung:**

Textdateien lesen, ohne versehentlich etwas zu verändern. Textr ist eine Lese-App für Android 10 und neuer – ohne Konten, Werbung, Analysefunktionen oder eigene Netzwerkberechtigung.

Öffne Dateien über die Android-Systemauswahl oder über Öffnen mit und Teilen in anderen Apps. Wähle zwischen Klartext, hervorgehobenem Quelltext und unterstützten Vorschauen für Markdown, JSON und Kalender. CSV-Dateien starten als Text und bieten eine optionale Tabellenansicht.

Durchsuche die Ansicht oder den vollständigen Quelltext, markiere und kopiere Text, passe Textgröße und Zeilenumbruch an und wähle eine helle oder dunkle Darstellung. Öffne zuletzt gelesene Dateien erneut, wechsle zwischen bis zu fünf Dokumenten und speichere benannte Lesezeichen. Eine optionale Dateiseitenleiste nutzt große Bildschirme auf Foldables und Tablets. Die Oberfläche ist auf Deutsch und Englisch verfügbar.

Textr unterstützt Textdateien bis 5 MiB, darunter TXT, LOG, Konfigurationen, JSON, Markdown, YAML, TOML, XML, CSV, Java, JavaScript, CSS, HTML-Quelltext, Kotlin, Python, Shell, SQL, Diff und iCalendar. Vorschau und Hervorhebung haben Grenzen; Klartext bleibt verfügbar.

Textr bearbeitet und verwaltet keine Dateien. Android entscheidet anhand der sendenden App und des gemeldeten Dateityps über Standard-Apps. Externe Dokumentanbieter können selbst das Netzwerk nutzen. Angetippte Links öffnen sich in einer anderen App. Markdown-Bilder und eingebettetes HTML werden nicht dargestellt; Kalenderwiederholungen werden nicht aufgelöst.

Freie Software unter GPL-3.0-only. Quellcode und Hilfe: https://github.com/utrost/Textr
